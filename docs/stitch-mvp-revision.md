# 媒体去重 App — Stitch 设计修改说明（MVP 可实现版）

> 给 Stitch 的修改任务书。现有 `stitch_media_deduplication_tool_ui` 设计主干可用，请按本文 **收敛、改写、补空态**，不要推倒重画。
>
> 产品原则：Windows 优先的桌面工具；会删用户文件，默认回收站；引擎以现有 Go `internal/*` 为准，**界面文案不得虚构未实现算法**。

---

## 0. 总原则（所有页面遵守）

### 0.1 技术表述必须诚实

| 禁止写成 | 应改为 |
|---|---|
| MD5 / xxHash64 / dHash / CRC32 混合引擎 | SHA-256（精确重复）+ pHash（感知近似） |
| pHash + dHash + MD5 / 多维哈希矩阵 | SHA-256 + pHash；视频为多帧 pHash |
| NVDEC / QSV 硬件解码就绪、GPU 仪表 | 可写「FFmpeg 抽帧」；**不要**硬件加速徽章 |
| AES-256 加密审计日志 | 可选简化为「本地操作记录」；或删除 |
| 扇区级抹除 / Shift+Delete 底层擦除 | 永久删除 = 跳过回收站直接删除（不可恢复） |
| 支持 RAW/HEIC 全量感知去重暗示 | HEIC/HEIF：**仅精确去重**；RAW 感知未承诺则不写 |
| 扫描中断 / 继续扫描 / 断点续扫 | **重新扫描（自动复用哈希缓存）** |
| 画质综合评估（色彩位深、P3、完整 EXIF 调色） | 推荐保留：基于分辨率等现有质量分；文案写「质量推荐」即可 |
| 差异像素高亮、同步播放、AES、双视频播放器 | **不在 MVP**（见各屏「删除/降级」） |

### 0.2 与已确认产品范围对齐

**MVP 做：** 多项目、目录（选择/拖拽/最近/失效）、参数、进度、结果筛选、组列表、组详情（缩略图网格+检视器）、视频帧条、忽略组、回收站删除（可选永久删）、导出 JSON/HTML/路径、全局设置与环境检查。

**MVP 不做：** 暂停/断点续扫、改阈值仅重匹配、并排像素差对比、应用内视频同步播放器、自动一键清空所有重复、云同步、硬件加速。

### 0.3 语言与平台

- 界面主语言：**简体中文**；路径/命令可用英文等宽字体。
- 窗口：Windows 为主 —— 标题栏右上角 **最小化 / 最大化 / 关闭**（不要 macOS 红黄绿交通灯作为唯一呈现；可兼容展示，但设计稿以 Win 为准）。
- 字体：Inter + 系统中文回退；路径/哈希/大小用 JetBrains Mono 或 Consolas。

### `10_8` 组详情（列表 + 右侧检视器）— **MVP 核心屏，优先精修**

**保留（主交互）**
