# 媒体去重 App — Stitch 分页设计任务书（总控文档）

> **用法（重要）**
> 1. 先把下面 **§0 产品背景** 整段发给 Stitch，作为项目共识（只需发一次；若新开会话可再发一次）。
> 2. 再按顺序，**一次只复制一个「页面 Prompt」**（§1、§2、…）发给 Stitch。
> 3. 每页设计完成后人工过一眼，再发下一页。不要一次贴多页。
> 4. 全部页面完成后，用 §12 自检清单收口。
>
> **工作流原则**：Stitch 一次只规划一个界面；不要让它「自己发挥整个 App」。

---

## §0 产品背景（先发，只发一次）

复制以下全部内容：

```text
【项目背景 · 媒体去重桌面 App】

这是一个本机运行的媒体去重桌面工具（Windows 为主，开发可在 macOS）。用户选择若干目录，扫描图片/视频中的精确重复与视觉近似重复，在界面里人工审阅后，把不要的文件移入系统回收站（可选永久删除）。

技术事实（界面文案必须诚实，禁止虚构）：
- 精确重复：SHA-256 文件哈希
- 图片近似：pHash 感知哈希 + 汉明距离
- 视频近似：FFmpeg 抽多帧 + 多帧 pHash
- 缓存：本机 SQLite，按 size+mtime 增量
- 默认删除：移入系统回收站；永久删除需设置开启 + 强确认
- 本工具从不自动删除文件；必须用户勾选并确认
- 不做：断点续扫、暂停、像素差高亮、并排同步播放器、硬件加速 NVDEC/QSV、MD5/xxHash/dHash、云同步

产品结构：
- 多项目：每个项目有自己的目录列表、扫描参数、结果与处理状态
- 主流程：项目列表 → 扫描配置 → 扫描进度 → 结果列表 → 组详情审阅 → 删除确认 →（可选）导出
- 另有：全局设置、空态与异常态

视觉方向（沿用你已有的 Functional Precision / 桌面工具感）：
- 浅色界面，高信息密度，少阴影，1px 边框分层
- 主色蓝 #2563EB；推荐保留用绿；待删/风险用红；待审核可用琥珀
- 正文 Inter + 系统中文字体；路径/哈希/大小用等宽（JetBrains Mono 或 Consolas）
- 圆角克制（控件 4px，容器 6–12px）；不要营销风大渐变、不要大圆角卡片堆
- 窗口：Windows 右上角最小化/最大化/关闭（设计稿以 Win 为主）
- 语言：简体中文为主，可混少量英文标签

请记住：你每次只做我指定的那一个界面。做完停下，等我发下一页任务。不要扩展到其他页面。
```

## §1 页面：项目列表（首页）

```text
【设计任务 · 页面 1/11：项目列表】

只设计「项目列表」这一屏。不要设计其他页面。

【用户目标】
打开 App 就能看到有哪些去重项目，新建或进入某个项目继续工作。

【必须包含】
1. 左侧全局导航（后续页面会复用，本页定下导航结构）：
   - 项目列表（当前页）
   - 扫描配置
   - 扫描进度
   - 重复结果（可显示未处理组数角标）
   - 全局设置
   导航下方可有：FFmpeg 就绪状态、累计释放空间（仅统计本机）
2. 主区标题：「项目列表」+ 副标题说明（管理本机去重项目）
3. 主操作：
   - 「新建项目」（主按钮）
   - 可选次按钮「从文件夹导入」（若实现可后置，视觉上可弱化）
4. 项目卡片列表（网格），每张卡片包含：
   - 项目名称
   - 状态角标之一：待处理 N 组 / 已全部处理 / 重新扫描
   - 扫描目录数量与路径摘要（截断）
   - 上次扫描时间
   - 待释放空间 / 已释放空间
   - 主按钮：「打开项目」
   - 次要：重新扫描（若未完成或可再扫）
5. 可选：搜索项目、按上次扫描/可释放排序
6. 空状态：还没有项目 → 大标题 + 说明（选择目录→扫描→审阅后移入回收站）+「新建项目」+ 3 步上手说明（纯本地、不上传）

【禁止】
- 「继续扫描 / 扫描中断 / 断点续扫」作为主操作（只允许「重新扫描」并注明复用缓存更快）
- 假版本营销（Core Engine v2.4.0 等可弱化为「本地引擎」）
- 「零破坏性覆盖」等夸张词 → 用「默认移入系统回收站，不覆盖原文件」
- 假统计若保留，须标注「仅统计本机已扫描项目」

【输出】
一张完整静态稿（含空状态可另附一张或分屏标注）。导航样式本页定稿，后续页面会沿用。
```

## §2 页面：扫描配置

```text
【设计任务 · 页面 2/11：扫描配置】

只设计进入某个项目后的「扫描配置」页。复用页面 1 的左侧导航与窗口框架。

【用户目标】
为本项目添加/管理扫描目录，调整参数，然后开始扫描。

【必须包含】
1. 面包屑：项目列表 › [项目名] › 扫描配置
2. 页头：标题 + 主按钮「开始扫描」+ 次按钮「保存配置」
3. 左栏 · 目录配置：
   - 添加目录按钮
   - 拖拽文件夹投放区（说明支持本机/移动硬盘/NAS 盘符）
   - 最近目录快捷添加（列表，点击加入）
   - 目录列表每行：路径、状态徽章（正常 / 目录不可用）、文件数与体积（可标「约」）、递归开关、打开文件夹、移除
   - 目录不可用态：红色条 + 说明（磁盘断开或路径失效）+「重新检查」「移除」
4. 右栏 · 扫描参数：
   - 相似度阈值滑条，默认 0.80，范围 0.50–1.00，旁注「越高越严格」
   - 视频去重开关（说明：MP4/MOV 等，依赖 FFmpeg）
   - 视频抽帧数量，默认 8（仅视频开启时显示）
   - 生成缩略图缓存开关（建议保持开启）
   - 高级参数折叠：并发数等（默认收起）
   - 勾选：「记住本项目扫描参数」
5. 底部摘要条：已选 N 个目录（M 个离线）+「开始扫描」
6. 技术徽章只允许写：SHA-256 + pHash（视频为多帧 pHash）

【禁止】
- MD5 / xxHash / dHash / CRC32
- 智能 AI 去重话术
- 扫描前精确预估「必得到 X 文件 / Y GB」；若显示体积须标「约·异步估算」，或只显示目录数

【输出】
一张完整静态稿（可含目录不可用的局部状态标注）。
```

## §3 页面：扫描进度

```text
【设计任务 · 页面 3/11：扫描进度】

只设计「扫描进行中」页。复用导航与窗口框架。

【用户目标】
知道现在扫到哪一步、扫到哪个文件、还要多久，并能取消。

【必须包含】
1. 面包屑：项目 › 正在扫描
2. 阶段条（5 段，名称如下）：
   1) 发现文件
   2) 精确哈希（SHA-256）
   3) 图片感知哈希（pHash）
   4) 视频抽帧（FFmpeg，可「已跳过」）
   5) 分组匹配
   当前阶段高亮；已完成打勾；未开始置灰
3. 主进度：总百分比环或粗条 + 已处理/总数
4. 当前文件：类型图标、文件名、分辨率/大小、完整路径（等宽、可截断）
5. 实时数字：已发现文件数、精确重复组、近似候选、跳过/错误数
6. 可选：耗时；预估剩余（弱化，可标「约」）
7. 操作：「取消扫描」
8. 取消后说明（小字）：已完成计算会写入缓存，重新扫描会更快
9. 完成后：主按钮「查看重复结果」

【禁止】
- MD5 / xxHash / dHash / AVX / NVMe Direct / GPU / 硬件加速徽章
- 「断点续扫 / 继续扫描」
- 营销仪表盘感过强（信息够用即可）

【输出】
一张扫描中静态稿；可用角标标注「完成后主按钮变为查看结果」。
```

## §4 页面：扫描完成摘要（可选过渡页）

```text
【设计任务 · 页面 4/11：扫描完成摘要】

只设计「扫描刚完成」的结果概览页（从进度页完成后进入）。复用导航。

【用户目标】
一眼看到扫出了多少组、大约能释放多少空间，然后进入审核。

【必须包含】
1. 成功横幅：「扫描完成，发现 N 个重复组」+ 耗时 + 文件数 + 预计可释放
2. 两张统计卡：
   - 精确重复（SHA-256）：组数、副本数、可释放
   - 近似重复（pHash）：组数、文件数、可释放
3. 可选小卡：媒体类型分布（图/视频）、跳过/错误数
4. 一行说明：已为每组标出「推荐保留」文件，需人工确认后删除
5. 主按钮：「进入重复结果审核」；次按钮：重新扫描、导出
6. 若无重复：改用空状态文案「扫描完成，未发现重复媒体」+ 说明当前阈值下均为独立文件

【禁止】
- xxHash、扇区擦除、垃圾桶 30 天承诺（回收站还原说明要准确）
- 过大装饰圆环/数据大屏（可轻量）
- 「一键智能清理全部」

【输出】
一张有重复结果的概览稿；可另附「无重复」空状态小稿。
```

## §5 页面：重复结果列表

```text
【设计任务 · 页面 5/11：重复结果列表】

只设计项目内的「重复结果」列表页。复用导航。

【用户目标】
筛选、排序、勾选多个重复组，批量进入处理或删除流程。

【必须包含】
1. 面包屑：项目 › 重复结果
2. 页头统计：重复组数、涉及文件、预计可释放
3. 筛选行：
   - 重复类型：全部 / 精确 / 近似
   - 媒体类型：全部 / 图片 / 视频
   - 处理状态：全部 / 未处理 / 已忽略 / 已处理
   - 排序：可释放空间 / 成员数 / 路径
   - 搜索：文件名或路径
4. 次操作：「勾选推荐删除项」（勾选各组中非推荐保留的成员，非自动删除）
5. 组卡片列表，每组包含：
   - 缩略图（主预览）
   - 组类型徽章：精确重复 / 近似重复（视频组写近似视频）
   - 组号与成员数、简短描述
   - 推荐保留路径一行
   - 可释放空间（大号数字）
   - 状态：未处理 / 已忽略 / 已清理
   - 操作：查看组详情；已忽略则「恢复处理」
   - 组级勾选框（用于批量）
6. 底部操作条：已选 N 组 / M 个副本、预计释放、主按钮「批量处理已选」（进入删除确认，不直接删）

【禁止】
- pHash 97% 之类的百分比（若无明确换算）；可用「pHash 距离」或不显示
- CRC32、MD5
- 「安全模式自动锁定」过度承诺 → 改为「已标出推荐保留」
- 自动一键清空

【输出】
一张含多种组状态（未处理/已忽略/已清理）的列表稿。
```

## §6 页面：组详情 · 图片组（MVP 核心）

```text
【设计任务 · 页面 6/11：组详情（图片组）】

只设计图片重复组的详情页。复用导航。这是 MVP 最重要的界面之一。

【用户目标】
在一组图片中看清每张差异，标出保留与待删，再执行回收站删除。

【必须包含】
1. 面包屑：结果 › 近似组 #N；上一组/下一组；忽略此组
2. 组头：标题、成员数、可释放、未处理状态、简短算法说明（pHash 汉明距离 ≤ N）
3. 快捷选择：仅选副本（保留推荐）/ 全选 / 取消 / 反选；显示已勾选 x/y
4. 左栏成员列表（或缩略图网格），每项：
   - 复选框
   - 缩略图
   - 文件名、路径
   - 大小、分辨率、修改时间
   - 徽章：推荐保留（绿）/ 待清理已勾选（红）/ 类型如 RAW·原图·压缩副本（有则显示）
5. 右栏检视器：
   - 大图预览
   - 当前文件元数据：格式、分辨率、大小、时间、pHash 汉明距离（相对推荐保留）
   - 按钮：在资源管理器中显示、复制路径、用系统看图打开
   - 「反转保留」：将当前文件设为推荐保留
6. 底栏：已选 N 个、共可释放、重置勾选、主按钮「移入系统回收站 (N)」
7. 永久删除入口：默认隐藏或弱化；若显示须注明「需在全局设置中开启」

【禁止】
- 左右并排对比、差值像素高亮、Space 翻转删除标记（不在 MVP）
- 「结构相似度 98.4%」等假百分比 → 用汉明距离
- 微信/设备智能路径推断（无数据就不要写）
- 假 EXIF 深度（镜头/色彩配置文件）除非明确作为「可选扩展字段」

【输出】
一张图片组详情完整稿（列表+检视器+底栏删除）。
```

## §7 页面：组详情 · 视频组

```text
【设计任务 · 页面 7/11：组详情（视频组）】

只设计视频近似组详情页。布局骨架与「图片组详情」一致（左列表 + 右检视 + 底栏删除），差异在预览与元数据。

【与图片组的差异 · 必须体现】
1. 组类型：近似视频组；说明基于多帧 pHash（FFmpeg 抽帧）
2. 成员行显示：时长、分辨率/帧率（若 ffprobe 有）、大小
3. 右栏检视器：
   - 视频封面（首帧或抽帧封面）+ 时长
   - 系统播放器打开（次按钮，非应用内双视频同步播放）
   - 抽帧条：N 帧缩略图 + 时间戳（核心差异点）
   - 元数据：编码、分辨率、帧率、码率、大小、pHash 汉明距离
4. 底栏删除与快捷选择与图片组相同

【禁止】
- 应用内双视频并排播放器、帧级 97% 相似徽章、MASTER-01/DUP-02 电影感动效
- D-Log / ProRes 等未从 ffprobe 确认的字段乱写（可用「编码 H.264/H.265」等常见项，标「以检测结果为准」）
- 音频波形对比

【输出】
一张视频组详情完整稿（可见抽帧条）。
```

## §8 弹窗：删除确认

```text
【设计任务 · 页面 8/11：删除确认弹窗】

只设计模态弹窗（可附带一层模糊背景下的列表页示意，但主体是弹窗）。

【用户目标】
在真正删除前核对文件清单与删除方式，避免误删。

【必须包含】
1. 标题：确认删除选中的重复媒体文件？
2. 副文案：操作将作用于本机文件，请仔细核对清单与处理模式
3. 摘要条：
   - 即将处理 N 个文件，共释放约 X
   - 来自 M 个组；保留的推荐文件不受影响
4. 待删文件清单（可滚动）：缩略图或图标、文件名、路径片段、大小、标签（副本等）
5. 清理模式单选（默认回收站）：
   A. 移入系统回收站 — 徽章「安全推荐」；说明：可在系统回收站还原
   B. 跳过回收站永久删除 — 徽章「不可恢复」；说明：直接删除，无法从回收站找回；仅当设置开启时显示此选项
6. 若选永久删除：必须出现强确认，例如勾选「我已核对清单，知晓永久删除无法恢复」
7. 按钮：取消（次要）+ 确认（危险色）；确认文案随模式变化：
   - 「确认移入系统回收站 (N 个文件)」
   - 「确认永久删除 (N 个文件)」
8. 可选小字：完成后展示成功/失败计数

【禁止】
- Shift + Delete、扇区底层擦除、SSD 清理效率 100%
- AES-256 审计日志；可写可选「本机操作记录」或不写
- 未确认就默认永久删除

【输出】
弹窗完整稿；可附「永久删除已选中」的第二状态（同一弹窗切换）。
```

## §9 页面：导出中心

```text
【设计任务 · 页面 9/11：导出中心】

只设计导出页（从结果页入口进入，不必做成一级导航的复杂程度）。

【用户目标】
把当前结果导出为报告或路径清单，便于存档或外部处理。

【必须包含】
1. 面包屑与标题「导出去重清单」
2. 导出范围（单选）：
   - 当前筛选视图 / 已勾选
   - 全部待处理组
3. 导出格式（三选一或多选）：
   - JSON：结构化组与文件（含 pHash 距离、推荐保留标记）
   - HTML：本地审阅报告
   - TXT：待删路径或全部路径清单
4. 简短说明：导出为只读报告，不修改媒体文件
5. 目标位置 + 「立即导出」

【禁止】
- MD5、AES-256、Base64 微缩略图、SHA 签名报告作为主功能
- 「全量审计日志」若无实现则不要作为主选项
- 夸大「合规审计 / 防篡改」

【输出】
一张简洁导出页（不要企业级审计中心观感）。
```

## §10 页面：全局设置

```text
【设计任务 · 页面 10/11：全局设置】

只设计全局设置页。复用导航。

【用户目标】
配置默认删除方式、FFmpeg、缓存，完成环境检查。

【必须包含】分类（左侧或分组）：
1. 默认扫描参数：默认阈值、是否扫视频、默认抽帧数
2. 删除与安全：
   - 默认清理方式：移入系统回收站（推荐）/ 永久删除（需每次仍确认）
   - 说明文案写清风险
   - 可选：忽略系统目录（若实现）
3. 缓存与数据库：
   - 缓存路径、占用、打开缓存目录、清理缩略图、重置缓存
4. 环境检查：
   - FFmpeg / FFprobe 是否就绪、路径、重新检测
   - 未安装：警告「视频功能不可用，仅图片去重可用」
5. 关于：本地运行、不上传网络；可写简单版本号

【禁止】
- NVDEC / QSV / 硬件加速 / GPU 解码
- AES-256
- 「30 天一键还原」（改为系统回收站还原）

【输出】
一张设置页（可分「环境检查」为主视图）；另附 FFmpeg 缺失警告态。
```

## §11 页面：空态与异常态合集

```text
【设计任务 · 页面 11/11：空态与异常态合集】

只设计异常与空状态规范（可做成 2×2 或分屏面板，不要做成新功能页）。

【必须覆盖 4 态】
A. 空项目 / 首次打开
   - 引导新建项目；3 步说明；强调纯本地
B. 扫描完成无重复
   - 文件数与体积；说明当前阈值下无重复；可调阈值重扫或返回
C. FFmpeg 缺失
   - 图片去重仍可用；视频跳过；提供重新检测环境；可选自定义 ffmpeg 路径入口（可链到设置）
D. 目录/盘符失效
   - 路径列表标红；说明设备可能断开；重新检测 / 移除此目录；历史结果不丢

【禁止】
- Rust Core 等与实现不符的技术栈宣传
- 双视窗像素差暗示
- 恢复操作写成破坏性删除

【输出】
一张四态面板稿（或四张清晰分屏），供实现时做成真实界面状态。
```
